# AI エージェントの作業・呼び出し規約

## 作業開始時

- 依頼内容から対象を `desktop/`、`mobile/`、`pages/`、またはリポジトリ全体に分類します。
- 変更前に、ルート `AGENTS.md` と対象サブプロジェクトの `AGENTS.md` を読みます。
- 現在の変更状況を確認し、依頼と無関係な既存変更は変更・削除・巻き戻しません。
- 生成済みコード、ビルド成果物、依存関係ロックファイルは、依頼または通常の生成手順で必要な場合にだけ変更します。

## 実装時

- 依頼に必要な最小範囲だけを変更し、サブプロジェクトをまたぐ変更は必要性を明示します。
- Desktop では UI（`src/`）と Rust バックエンド（`src-tauri/`）の責務を分離します。
- Mobile では Expo Router のルーティング、タッチ操作、安全領域、および Drizzle のマイグレーション規約を守ります。
- Pages では `src/` 配下にコンテンツ・コンポーネントを配置し、静的サイトとしての構成を保ちます。
- ソースコード中のコメントは、必要な箇所だけに簡潔な英語で記述し、絵文字や変更履歴を書きません。

## エージェント間の引き継ぎ

複数のエージェントまたはセッションで作業する場合、呼び出す側は次を伝えます。

- 目的と完了条件
- 対象ディレクトリ・対象ファイル
- 変更してよい範囲と、触れてはいけない既存変更
- 実施する検証方法

作業を引き継ぐ側は、変更内容、未解決事項、実行済みの検証結果を短く返します。未検証の内容を検証済みとして扱いません。

## 完了前の確認

- 変更したファイルを見直し、無関係な差分がないことを確認します。
- 変更内容に見合う検証を実行します。実行できない場合は、理由を明示します。
- 実装・ドキュメント・生成コードの整合性を確認します。
- 最終報告には、変更の要点、検証結果、残る制約または注意点を含めます。
