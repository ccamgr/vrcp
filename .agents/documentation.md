# Documentation and Operations Rules

対象は `docs/`、`.agents/`、エージェント入口ファイル、デプロイおよびリリース設定です。

- 継続的に参照する資料は対象別に `docs/desktop/`、`docs/mobile/`、`docs/pages/` へ置きます。
- 一時的な移行記録は `docs/migrations/` に置き、現行仕様の正本として扱いません。
- 実装、生成手順、ドキュメントの内容を一致させます。
- エージェント固有の入口ファイルには規約本文を複製せず、`.agents/` の正本へルーティングします。
- リリースやデプロイに影響する変更は、対象サブプロジェクトの規約とワークフローを確認してから行います。
