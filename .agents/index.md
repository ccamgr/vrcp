# AI Agent Rules Index

このディレクトリが、Codex、Claude Code、GitHub Copilot で共有するプロジェクト規約の正本です。

| 作業対象 | 必ず読む規約 | 追加で読む規約 |
| --- | --- | --- |
| 全作業 | [common.md](./common.md) | 対象サブプロジェクトの `AGENTS.md` |
| `desktop/` | [desktop/instructions.md](./desktop/instructions.md) | [`docs/desktop/README.md`](../docs/desktop/README.md) |
| `mobile/` | [mobile/instructions.md](./mobile/instructions.md) | [`docs/mobile/README.md`](../docs/mobile/README.md) |
| `pages/` | [pages/instructions.md](./pages/instructions.md) | [`docs/pages/README.md`](../docs/pages/README.md) |
| `docs/`、`.agents/`、デプロイ・リリース | [documentation.md](./documentation.md) | 必要に応じた対象サブプロジェクト規約 |

エージェント固有の入口ファイルは、この規約を参照するだけに保ちます。規約を変更する場合は、まずこのディレクトリを更新します。対象別規約と共通規約が矛盾するときは、対象別規約を優先します。
